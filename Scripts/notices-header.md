# Third-party notices

Captions is built on other people's work. This file lists every library compiled into the app
and every model it downloads, with the terms each is used under. It is generated by
`Scripts/make-notices.sh`; edit `Scripts/notices-header.md` rather than the output.

## Speech models

The app downloads these on first use from Hugging Face (FluidInference's Core ML conversions).
They are not part of this repository.

- **Nemotron Speech Streaming 0.6B** (`nvidia/nemotron-speech-streaming-en-0.6b`), used when
  "Speech model" is Nemotron. Licensed by NVIDIA Corporation under the NVIDIA Open Model License.
  https://www.nvidia.com/en-us/agreements/enterprise-software/nvidia-open-model-license/
- **Streaming Sortformer v2.1** (`nvidia/diar_streaming_sortformer_4spk-v2.1`), which tells
  speakers apart. Licensed by NVIDIA Corporation under the NVIDIA Open Model License.
  https://www.nvidia.com/en-us/agreements/enterprise-software/nvidia-open-model-license/
- **Parakeet Unified 0.6B** (`nvidia/parakeet-unified-en-0.6b`), used when "Speech model" is
  Parakeet Unified. Creative Commons Attribution 4.0 International (CC-BY-4.0), by NVIDIA.
  https://creativecommons.org/licenses/by/4.0/

The Hugging Face cards for some of FluidInference's conversions name a different licence from
NVIDIA's originals. The terms above are NVIDIA's, which are the ones that govern the weights.
